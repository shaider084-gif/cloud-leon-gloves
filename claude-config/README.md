# Claude Code config (скиллы)

Все скиллы (292 шт.) устанавливаются не вручную, а через маркетплейс плагинов
`claude-plugins-official` (официальный маркетплейс Anthropic). Поэтому в
репозитории хранится не сами файлы скиллов, а только конфиг, который
подключает этот маркетплейс — Claude Code сам подтянет актуальные скиллы.

## Как восстановить на новом ПК

1. Установи Claude Code.
2. Склонируй этот репозиторий.
3. Скопируй содержимое `claude-config/settings.json` в `~/.claude/settings.json`
   (создай файл, если его нет; если файл уже существует — слей ключ
   `extraKnownMarketplaces` вручную, не затирай остальные настройки).
4. Перезапусти Claude Code — маркетплейс и все скиллы подтянутся автоматически.

## Если появятся свои (кастомные) скиллы

Кастомные скиллы, написанные вручную (не из маркетплейса), стоит класть
в отдельную папку `claude-config/skills/` в этом репозитории и копировать
в `~/.claude/skills/<имя>/` на каждом ПК — такие файлы маркетплейс не
подтянет сам.
