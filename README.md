# cloud-leon-gloves

Репозиторий для хранения файлов (прайс-листы поставщиков и т.д.) и
конфигурации Claude Code, чтобы работать с одинаковыми скиллами и
файлами с любого ПК.

## Структура

- `claude-config/` — конфиг Claude Code (маркетплейс скиллов). См.
  [claude-config/README.md](claude-config/README.md) для восстановления
  на новом ПК.
- прайс-листы и прочие рабочие файлы — будут добавлены позже.
